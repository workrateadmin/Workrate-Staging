4. HMRC GATEWAY SECURITY
==================================================

If a gateway is required, design it so:

- only WorkRate can call it
- HMRC tokens never reach the browser
- tenant/business ownership remains enforced
- forwarded-client information cannot be spoofed
- secrets remain encrypted
- logging contains no HMRC tokens or sensitive tax data
- sandbox and production are strictly separated
- requests are idempotent where relevant
