WORKRATE — RESTRUCTURE NAVIGATION + SETTINGS INTO CLEAN CATEGORY PAGES

GOAL:
Remove the cluttered horizontally scrolling top navigation and reorganise WorkRate into:

1. A focused day-to-day workflow top navigation
2. A Settings landing page with separate category pages
3. Dedicated setup/configuration pages rather than one giant settings page

IMPORTANT:
Do NOT rebuild backend logic.
Do NOT change existing feature behavior.
Do NOT delete existing routes or configuration.
Reuse existing pages/components/APIs where practical.

==================================================
1. TOP NAVIGATION
==================================================

The top navigation should contain ONLY everyday operational workflow areas:

- Dashboard
- Enquiries
- Jobs
- Schedule
- Quotes
- Invoices
- Finance

Remove from main top navigation:

- AI Receptionist
- Integrations
- Plan & Billing
- Diagnostics
- other configuration/admin destinations

Settings should remain accessible via profile/settings control or one dedicated Settings entry.

IMPORTANT:
No horizontal scrolling navigation on normal desktop widths.

If space becomes constrained:
use responsive collapse/menu behavior rather than a scrollbar.

==================================================
2. SETTINGS LANDING PAGE
==================================================

Create/upgrade Settings into a clean category landing page.

Do NOT display every setting directly on this page.

Show category cards:

BUSINESS

COMMUNICATIONS & INTEGRATIONS

BILLING

ACCOUNT & SECURITY

ADVANCED

Each card should:
- have icon
- title
- short description
- open a dedicated settings page
