5. AI RECEPTIONIST METERING
==================================================

Use the existing Vapi call data.

When a completed billable call is finalized:

record the actual call duration used for billing.

Prefer provider-reported duration when trustworthy.

Store usage in seconds internally if useful, but present customer allowance in minutes.

Do not double-count webhook retries.

Use provider call ID as part of deduplication.

Example:

Vapi call ID abc123
Duration 7m 22s

→ record one usage event representing 442 seconds
→ aggregate to monthly AI Receptionist usage

Do NOT meter:
- failed connection attempts with zero provider charge unless provider bills them
- page views
- opening a call record
